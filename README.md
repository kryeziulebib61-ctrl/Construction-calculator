# BETA GROUP-cal — slovenska različica

Moderna mobilna različica gradbenega kalkulatorja v slovenščini.

Vključuje 20 ključnih formul: diagonala, površina, beton, kot, naklon, armatura, masa betona, tlak, stopnice, trikotnik, krog, valj, temelj, streha, izkop, opeka/bloki, omet, barva, ploščice in obseg.

Pripravljeno za GitHub Pages.

## Logotip podjetja
Za zdaj je v glavi začasni znak **BG**. Pravi logotip podjetja lahko vstavimo v aplikacijo kot sliko.

Izračuni so informativni. Statično dimenzioniranje in varnost mora preveriti usposobljen strokovnjak v skladu z veljavnimi standardi.
